# 🐢 Save Turtle – Marine Turtle Conservation Platform

**A community-based educational platform for marine turtle conservation in Sri Lanka.**

Save Turtle is a web application developed to educate local communities about marine turtles, raise awareness of conservation challenges, and encourage public participation in protecting marine turtle species around Sri Lanka.

The platform provides educational resources, information about turtle nesting beaches, conservation events, threat reporting, and fundraising opportunities to support marine turtle protection.

## 🌊 Project Overview

Marine turtles play an essential role in maintaining healthy marine ecosystems. However, they face several threats, including illegal egg collection, fishing-related injuries, habitat destruction, pollution, and unregulated hatchery practices.

Save Turtle aims to bridge the knowledge gap between local communities and marine conservation initiatives by providing an accessible online platform where users can learn, participate, report threats, and contribute to conservation efforts.

## 🚀 Getting Started

### Prerequisites

Make sure the following tools are installed:

- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/)
- [Git](https://git-scm.com/)
- npm (included with Node.js)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Abiraj21012/GRP30_Save-turtle.git
```

**2. Navigate to the project directory**

```bash
cd GRP30_Save-turtle
```

**3. Install dependencies**

Navigate to the frontend and backend directories, if the project separates them, and run:

```bash
npm install
```

**4. Configure the environment**

Configure the required environment variables, including the MongoDB connection string and any other settings expected by the application.

**5. Start the application**

Run the appropriate development commands defined in the frontend and backend `package.json` files.

*Note: The exact startup commands and environment variable names depend on the repository's current configuration.*

## 🌱 Expected Impact

Save Turtle aims to make marine turtle conservation information more accessible and encourage communities to take an active role in protecting marine life.

## 🔬 Research Background

This project is associated with the research paper:

**“Effective Community-based Education of Marine Turtles in Sri Lanka: Assessment of Details, Threats, and Conservation Strategies Undergoing in Sri Lanka.”**

The research explores marine turtle species in Sri Lanka, their nesting behavior, conservation challenges, existing protection strategies, and the potential role of community-based education.
